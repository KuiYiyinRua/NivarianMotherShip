# 涅瓦莲折跃舰

先完成“跨域人员折跃”，再在上行链路中单独研究“涅瓦莲折跃舰”，即可建造。

| 项目 | 设置 |
| --- | --- |
| 占地、基础生命值 | 3×3 格、350 |
| 载重、武器 | 1000 kg、无武器 |
| 飞行速度 | 与引力舰相同 |
| 燃料容量 | 600 化合燃料 |
| 地图飞行与能量场耗油 | 每 10 秒 1 单位，为引力舰的一半 |
| 世界航行耗油 | 每格 0.75，最低 12.5，为引力舰的一半 |
| 建造材料 | 龙霜钢 255、塑钢 150、高级零部件 5、龙晶 85、黄金 42、低温冷却剂 21 |
| 研究 | 5000 点；钢铁 500、高级零部件 10、龙晶 150 |

升空后，选中舰船，点击底部的“能量场模式”。展开和收拢均需要 1 秒游戏时间。展开后舰船缓慢原地旋转，无法移动、降落或进行舰船折跃，仍处于飞行状态并消耗燃料。

半径 6 格的蓝色蜂窝范围以舰船为圆心。部署过程会消除悬浮绘制偏移，退出时恢复悬浮高度。显示范围与实际覆盖范围一致，完整继承原有建筑供电及单位充能；同一地图上主能量场和所有折跃舰共用 10000 W 供电上限。

殖民者的折跃按钮会列出主能量场和已展开的折跃舰，支持跨地图选择。舰船只能前往主能量场；折跃舰须先收拢回飞行模式。人员和舰船折跃沿用当前公共的 4 秒折跃流程。目的地失效会取消折跃。

停泊时可用与引力舰相同的 2 份电池材料升级：米莉拉星舰电池和不稳定能量电池各计 1 份，虚空电池计 2 份，支持混用；原版电池需先卸载打包。升级后每次起飞消耗 50 化合燃料，飞行及能量场维持不再持续耗油。

飞行贴图的可见宽度采用初版的 85%，高度保持不变；能量场形态使用独立的中心对称展开贴图。没有独立操作点，加油、装载和电池交付使用船体的正常接触位置。

联机需要所有玩家安装同一版本，并包含 `Multiplayer/Assemblies/NivarianCommander.WarpPrism.Multiplayer.dll`。测试仅覆盖短功能流程，不包含长时间压力测试。
