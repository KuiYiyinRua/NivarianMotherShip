# 涅瓦莲暴风舰

在上行链路中独立研究「涅瓦莲暴风舰」后，可通过涅瓦莲建造系统制造。科技前置与航母相同：涅瓦莲引力舰、涅瓦莲舰队支援协议、超维空间矩阵投射支援协议（`NMC_GravityFrigateResearch`、`NMC_Support13`、`NMC_Support19`）。暴风舰研究没有额外的任务解锁条件。

## 基础规格

| 项目 | 数值 |
| --- | --- |
| 占地 | 5×5 格 |
| 基础生命 | 2000 |
| 载重 | 3500 千克 |
| 射程 | 100 格 |
| 武器间隔 | 180 tick，正常速度下约 3 秒 |
| 直击 | 20 伤害，80% 穿甲，对建筑 ×5 |
| 爆炸 | 落点周围严格 3×3 格，25 伤害，35% 穿甲，对建筑 ×5 |

目标建筑在没有额外增减伤时，受到 100 点直击与 125 点爆炸伤害。范围内其他建筑受到 125 点爆炸伤害；大型建筑每次爆炸只结算一次。爆炸没有距离衰减，也不扩展至相邻范围外的格子。舰船武器与装甲研究仍按现有系统提高其属性。

升空后自动攻击敌人，也可通过「雷暴球攻击」指定目标、取消指定目标或关闭自动开火。指定目标优先于自动搜索。降落与折跃过程中停止发射，已经发出的雷暴球继续飞行，保存与读档保留在途弹丸。

## 材料与研究

建造耗材均为航母的 70%：龙霜钢 1050、塑钢 525、高级零部件 21、龙晶 420、黄金 280、冷凝液 70。

研究耗材同样为航母的 70%：龙霜钢 350、高级零部件 7、龙晶 140。基础研究量 10500；实际显示数值遵循游戏和本体的研究倍率。

## 飞行、折跃与动力升级

地图内飞行速度为每 tick 0.055 格，与航母相同。化合燃料容量为 10000；未升级时，升空及地图内飞行每 60 tick 消耗 1，世界航行每格消耗 3、最低 50。世界航行沿用现有原生穿梭机运输、驾驶员、起降与货舱流程。

研究能量场折叠后，可使用舰船的折叠按钮前往已部署的主能量场。原地准备与实际落点打印各持续 240 tick，两个阶段正常受伤；保留货舱、动力升级和飞行状态。

停泊时可安装 5 份电池，正好是航母的半数：米莉拉星舰电池、不稳定能量电池各计 1 份，虚空电池计 2 份，可以混用。原版建筑电池需要先卸载打包。升级未完成时可取消并退还已投入的实际电池。升级完成后，每次起飞消耗 200 化合燃料，地图飞行和世界航行不再持续耗油。

贴图采用白灰装甲、深色结构和青蓝能量节点；舰体与弹丸使用用户最终选定的明亮球核和细分叉电弧样式。

发射与命中音效取自用户提供的攻击演示视频，分别在弹丸发出与落点爆炸时播放。录音经裁切、低频杂音过滤、首尾淡化及音量调整，保留原音色和速度；使用地图内的位置音效，随距离衰减。命中音效每枚弹丸只播放一次，不按爆炸覆盖格数重复播放。

## 联机

新增独立 `NivarianCommander.StormShip.Multiplayer.dll`，同步指定目标、自动开火与清除目标，携带来源地图上下文。原有联机适配器保持不变；升降、移动、升级与能量场折叠复用已有同步入口。所有玩家需要更新相同文件并重新启动游戏。
