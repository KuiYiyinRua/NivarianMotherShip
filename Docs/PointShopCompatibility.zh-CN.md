# 1.7 点数商店图形兼容

GitHub issue #1 的崩溃报告记录了 `ImGuiMaterialRenderer.CreatePipeline` 调用 `vkCreateGraphicsPipelines` 返回 `VK_ERROR_UNKNOWN`。环境为 RimWorld 1.7.4985 rev1269、Radeon RX 560X、AMD 25.8.1、独立 RimUnity 0.1.17。日志没有失败 Shader 的名称，不能将唯一责任归给头像材质、运行库或显卡驱动。

本模组在 1.7 商店内避开自定义 UI 材质管线：Nira 头像使用原贴图与原打字效果，不创建全息投影材质；商品沿用原生贴图解析、角度、比例、样式和基础颜色，以普通 UI 贴图绘制。特殊图标的材质遮罩、发光等效果不再执行。兼容逻辑只在本模组商店调用，不修改依赖模组、全局渲染器或交易状态。

1.6 分支保留原头像和商品绘制方式，本次只部署 1.7 核心。原 r9 的连续体重试修复仍包含在新核心中。更新后须完全退出并重启游戏。

验证：r9 原核心在材质提交边界的回归测试中有 7 项失败；候选在嵌入式 RimUnity 0.1.16 和独立 0.1.17 下各通过 29 项检查，共 58 项，含六轮实际开关商店、页面切换、滚动、材质图标注入与截图检查。正式候选没有提交自定义 UI 材质。测试拦截器只存在于隔离探针中，不随核心加载。

1.7 构建及独立源码重建为零警告、零错误，生成核心相同；共享源码的 1.6 编译检查也通过。核心 SHA-256：`D8EA5688B69996CE2E5B32F0031A7A08E3E7F536AE6B5DC1858A9A6D961D63B4`。证据位于本地 `BuildValidation/PointShopCompat17-20261025`，回归入口为 `Tests/PointShopCompat17`。

本机测试使用 NVIDIA RTX 2080 Ti，未复现对方 AMD 驱动故障，也未验证其实际存档或完整整合包。此修复消除了已识别的商店自定义材质入口；仍需在受影响电脑上复测。未进行 1.7 联机认证。
