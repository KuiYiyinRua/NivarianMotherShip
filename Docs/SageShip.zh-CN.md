# 涅瓦莲贤者舰

贤者舰通过上行链路中的独立研究解锁。前置为“太阳能射线枪支援协议”，与引力舰同级，不要求完成引力舰研究，也没有额外任务解锁条件。

| 项目 | 设定 |
| --- | --- |
| 占地 / 基础生命 / 载重 | 2×2 / 350 / 200 kg |
| 操作点 | 不设独立操作点 |
| 攻击开关 | 默认关闭；升空并开启后自动索敌，也可指定地面目标 |
| 武器 | 12 格；每 30 tick（0.5 秒）同时发射两束蓝色棱晶激光 |
| 每束伤害 / 穿甲 | 6 / 30%；使用既有舰船武器研究加成 |
| 射击燃料 | 每次双束齐射共消耗 1 化合燃料；升级电池后仍消耗 |
| 对空限制 | 飞行舰船、无人机、舰载机、被引力束抬升的单位均不可攻击 |
| 反隐 | 半径 50 格，包含边界；对敌方生效，停泊或关闭攻击时仍有效 |
| 反隐恢复 | 不永久删除隐身来源；离开范围后按原隐身来源的恢复时间恢复 |
| 地图速度 | 0.2875 格/tick；引力舰为 0.23，提升 25% |
| 世界速度 | 原生世界航行速度 ×1.25 |
| 地图耗油 | 每 600 tick（10 秒）1；引力舰每 300 tick 1 |
| 世界耗油 | 每格 0.75，最低 12.5；均为引力舰的一半 |
| 燃料容量 | 600 |
| 星舰动力升级 | 1 份；支持米莉拉星舰电池、不稳定能量电池、虚空电池，按完整物品投入 |
| 升级后动力 | 每次起飞 50 燃料、免持续飞行耗油；攻击照常耗油 |
| 折跃 | 接入原有能量场召回，保留货舱、飞行状态和电池升级 |

建造材料：龙霜钢 150、塑钢 88、高级零部件 3、龙晶 50、黄金 25、低温冷却液 13。引力舰对应材料的半价不能整除时向上取整。

研究量 3000；材料为钢铁 300、高级零部件 6、龙晶 90，均为引力舰的一半。建造工量 25000，建筑技能要求沿用引力舰。

贴图来自内置 ImageGen，参考用户四张舰船设计图和现有涅瓦莲舰船。前两稿按用户意见弃用，第三稿确立紧凑环翼、球形核心和中央尖脊；本轮在该稿基础上减少核心网纹、细小分缝和重复灯条，补齐纯黑外描边。当前透明 PNG 位于 `1.6/Textures/NMC/Fleet/sage_ship.png`；本轮提示词、修改前后对照和备份位于 `Artwork/FleetOutline20261013/`，原功能版生成与验证证据保留于 `BuildValidation/SageShip-20261013/`。

新指令的联机同步位于独立的 `NivarianCommander.SageShip.Multiplayer.dll`；原有四份联机程序集保留。攻击模式和指定目标以源地图为上下文同步，视觉显示不驱动模拟；半径探测读取当前地图的真实舰船位置，不使用本地界面缓存。
