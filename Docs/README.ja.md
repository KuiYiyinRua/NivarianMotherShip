# Nivarian Race: MotherShip

バージョン **0.9.8**。RimWorld **1.6** 対応。簡体中文、英語、ロシア語、日本語、フランス語を収録しています。

19 種の戦術支援、ポイントショップ、空母、重力艦、8 段階の連続体任務を追加します。

## 導入

[Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3817608894) から MOD の ZIP をダウンロードし、NivarianMotherShip フォルダーをゲームの Mods フォルダーへ展開してください。更新時は古いコピーを置き換えます。

Harmony、Humanoid Alien Races、Nivarian Race、本拡張の順に有効化し、基礎 MOD の依存関係も満たしてください。依存 MOD は同梱していません。ゲーム設定で言語を選択し、データの再読み込みを待つと反映されます。

Royalty が有効なら標準のサイキャストと連携し、無効なら代替能力を使用します。Multiplayer の連携は自動読み込みです。ミリラ種族 MOD のバッテリー改良は任意です。連続体任務にはニヴァリアン軍工拡張が必要で、無効の場合は支援研究を直接進められます。

## 遊び方

母艦支援ウィンドウで司令官ページを開き、アップリンク研究端末で支援プロトコルを解放します。費用や対象制限はゲーム内に表示されます。

空母の改良にはミリラの星艦バッテリー 10 個、重力艦には 2 個が必要です。改良を指示すると入植者が搬入・設置します。設置後の燃料消費は離陸時のみです。

0.9.6 の精密友軍識別は、軌道攻撃支援に続く独立研究です。研究量 3000、スチール 250、工業用コンポーネント 8、竜晶 30 を必要とします。完了すると友軍への誤射防止が永続的に有効になります。以前購入した保護は維持され、研究完了へ自動移行します。

[開発・翻訳の保守](../README.md)

## 研究の解放設定

作者：尹怨怨。MOD設定 → Nivarian Race: MotherShip の「ミッションなしで拡張の全技術を解放」は初期状態でオフ。オンにして再開すると、本拡張の全38研究が完了し、戦役と支援の母艦レベル条件を省略します。費用とクールダウンは継続。オフに戻しても研究は残り、レベル条件が復帰します。他MODの研究・戦役クリア記録には影響しません。マルチプレイでは同期されたワールド設定を使用します。
