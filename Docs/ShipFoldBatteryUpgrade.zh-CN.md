# 舰船能量场折叠与星舰动力升级

完成原有「能量场折叠」研究后，玩家的引力舰、航母及召唤舰队（战术母舰、驱逐舰、虚空辉光舰、佐拉雅）显示折叠按钮。点击会移至当前能量场内能容纳整个舰体的空位，可跨已加载的地图。保持原朝向、飞行状态、货舱、乘员、升级进度；航母先收回舰载机。跨图时停止该舰在旧地图的装载任务，已经入舱的内容随船移动。起降或入场折跃中不可使用。没有合适空位、能量场已撤销或按钮对应的场已改变时拒绝执行。召唤舰队的持续时间仍由原来的来源地图推进，折叠不延长寿命。

引力舰需要2份电池，航母需要10份。米莉拉星舰电池和 Royalty 的不稳定能量电池每个计1份；原版虚空电池每个计2份，三种可混合使用。不要求启用米莉拉；未启用 Royalty 时仍可用 Core 的虚空电池。原版两种电池是建筑，须先用原版卸载命令打包，殖民者才能搬入。最后一份若投入虚空电池，会使用整个电池完成升级。

停泊时点击「升级星舰动力」。进行中同一按钮变成「取消升级（已投入/需求）」，再次点击退还全部已投入的实际电池，保留打包状态和损伤；可堆叠电池按原版规则合并，退还数量不变。退款出现在舰船附近；失败的放置仍保留在船内，不会丢失，后续取消可重试。已完成的升级不提供拆除按钮。完成后的燃油效果与原来一致：引力舰每次起飞100化合燃料，航母200，随后地图内和世界航行不再持续耗油。

旧存档已投入但尚未完成的米莉拉电池数量可退款；旧版已经消耗实体，因此按数量重建米莉拉电池，米莉拉定义不存在时优先退还等量不稳定能量电池。旧档没有电池定义可恢复时保留进度，不静默丢弃。

第三方电池可在 ThingDef 上加入以下扩展，`units` 为每个电池贡献的整数份数；可搬运的物品或打包建筑均能被现有升级工作扫描发现。

```xml
<modExtensions>
  <li Class="NivarianCommander.StarshipBatteryEquivalent">
    <units>1</units>
  </li>
</modExtensions>
```

核心接口为 `AircraftStarshipUpgrade.BatteryUnits(ThingDef)`、`DeliveryCount(Building_NivarianAircraft, Thing)` 与模拟过程中的 `Deliver`。取消和舰船折叠由独立可选程序集 `NivarianCommander.ShipUpgrades.Multiplayer.dll` 同步。原有 `NivarianCommander.Multiplayer.dll` 保持原二进制，不重复登记已有的升级开始命令，也不接管现有随机数补丁。双方须安装相同完整文件并重启游戏；不需要修改 MP-Race-Compatibility-Plus。
