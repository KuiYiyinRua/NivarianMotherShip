# 能量场折跃修复与远行队入口

完成原有“能量场折跃”研究后，选中世界地图上的己方远行队，点击“折跃至能量场”，再选择主能量场或已展开的折跃棱镜。目标必须位于当前已加载的地图。

整队人员、动物、囚犯及随身物资一同进入目标地图。抵达后播放4秒打印效果，期间正常受伤。执行前为所有成员检查并保留落点；空间不足或目标失效时，整支远行队留在原处。抵达后按原版进入地图流程处理远行队、动物和囚犯。

人物原有的地图内/跨地图折跃继续使用4秒准备、4秒抵达效果。修复了打印材质在人物并行预绘制线程中加载 Unity 资源而导致的原生崩溃；资源加载、材质创建与进度更新现在由主线程完成。

联机时需要所有玩家使用相同的核心模组和联机适配器，并重启游戏。远行队确认操作同步为世界命令，以远行队、地图、棱镜的稳定ID和目标修订号重新校验目标。

本轮测试记录位于 `BuildValidation/FieldWarpCaravan-20261015/`。该改动纳入 0.9.9-r2 全量更新；测试范围与限制见 VALIDATION.md。
