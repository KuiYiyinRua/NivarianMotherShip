# 巨石与能源塔 tick 优化（2026-10-21）

已修改源码，并将实测候选安装到 `1.6/Assemblies/NivarianCommander.dll`。重启游戏后生效。联机双方需使用相同文件。

## 修改

- `CompMonolithWeapon.CompTick`：使用原生 Pawn、人工建筑分类列表，额外补全天然/特殊建筑及非 Pawn 无人机。复用选择缓冲区，以小型有序列表保留最近的目标，省去全地图 LINQ 过滤、完整排序及每次扫描的新列表。
- `CompMonolithWeapon.ValidTarget`：在隐身、外交和视线查询前过滤距离；超过已选目标上限且排序更后的候选无需再做昂贵判断。仍逐 tick 寻找目标，原距离优先、Thing ID 次序、攻击间隔和时空波动冷却规则保持。
- `NutritionStored` 使用索引遍历，保留原累加顺序和实时食物属性。`NutritionNeeded`、`CanReceiveNutrition` 使用这一实现；自动补料判断只计算一次储量，投料接受检查不再重复计算缺口。
- 能源塔缓存组件引用、定义扩展引用及当前 Game 的账本引用；原生扩展的日程、仪式和自动供电开关仍走完整判断。缓存不保存营养数值、阵营、开关状态或运行状态。
- `HasNutrition` 与 `Tick` 在数值缓冲足够时直接判定，避免每 tick 多次检查食物；Tick 复用本次耗用量。`IsOperating` 先排除断电。
- 暗影范围查询先检查几何覆盖，再访问能源塔运行状态，减少范围外单位触发的营养和供电查询。

## 性能记录

以下是隔离游戏中的方法微基准，不代表整局 TPS 的同比提升。完整场景包含 6,059 个物体，其中 6,000 个是无关物品，另有 48 座敌方建筑及一个原生无人机。

原 DLL 与候选 DLL 各取五轮样本，中位数：

| 方法/场景 | 原版 μs/次 | 候选 μs/次 | 耗时减少 |
|---|---:|---:|---:|
| 巨石无目标 `CompTick` | 105.442 | 5.632 | 94.7% |
| 能源塔 `Tick` | 4.076 | 0.874 | 78.6% |
| 范围外隐身查询 | 1.939 | 0.501 | 74.1% |

同一候选进程、同一暂停场景中，原全图选择算法参考实现为 233.923 μs/次，新选择器为 35.150 μs/次，返回的目标及顺序相同。

第一轮跨进程的小属性计时波动明显，不能据此判断 `NutritionStored`/`NutritionNeeded` 的变化。因此补做了同进程、固定食物/数值缓冲、七轮交替执行的长批次参考算法对照：

| 属性 | 原算法参考 μs/次 | 当前 μs/次 | 耗时减少 |
|---|---:|---:|---:|
| `NutritionStored` | 0.3402 | 0.2841 | 16.5% |
| `NutritionNeeded` | 0.3434 | 0.2900 | 15.5% |
| `CanReceiveNutrition` | 0.9027 | 0.3056 | 66.1% |
| `HaulDestinationEnabled` | 1.2474 | 0.3069 | 75.4% |
| `OperationPermitted` | 1.2266 | 0.1360 | 88.9% |
| `IsOperating` | 1.9669 | 0.2223 | 88.7% |

参考属性实现含少量委托调用开销，复合属性百分比为近似值。原始五轮及交替七轮样本均保留，不删除波动较大的结果。`ValidTarget` 的效果包含在选择器测量中，没有单独给出其耗时百分比。

### 测试边界与诊断记录

本次是干净受控场景，未覆盖完整玩家整合包、代表性玩家存档、多地图异步、多阵营或冷重连。发现的近期本地玩家存档来自 `1.6.4633`、146 项加载，且未包含本母舰模组，未用它替代本次专项输入。探针会维持工作人员需求、修复测试靶建筑，并在长测必要时添加受控食物，以持续覆盖攻击和供能；后半段不等同于无人干预的原生搬运调度测试。

前期无效/中止记录全部保留：Prepatcher 内存加载导致探针读取空 Assembly.Location、深目录超过 Unity 素材路径限制、自然岩石压缩保存不能被测试组件引用、测试电缆重叠导致冷加载时塔离图，以及探针对电网分批重启和部分食物堆交付的错误预期。修正均限于探针/夹具，正式优化 DLL 未修改。`Smoke-R5/R6` 已执行部分操作且两端记录一致，但不计完整通过。

两轮有效日志仍有现有的 InputLegacyModule reflection-only 预加载提示、重复音效/翻译提示，以及探针移除生成动物时的 `Deep-saving destroyed thing` 提示；不声称这些提示已修复，也未据此声称生成动物清理后的冷重连安全。有效运行的同步、功能和最终状态检查均通过。
