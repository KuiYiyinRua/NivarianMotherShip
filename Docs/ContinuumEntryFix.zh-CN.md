# 连续体基地入场与登舰判定修复

2026-10-17。本次修改属于涅瓦莲母舰扩展 `NivarianMotherShip`。

## 原因与修正

旧版 `ContinuumBattlefield.MapComponentTick` 仅检查 `AllPawnsSpawned`，并在入场累计时间超过 600 tick 后，将一次“没有地面玩家单位”永久记为撤退。角色登舰后不在该列表内，虽然原生基地仍保留地图，世界任务组件却立即结束任务并清除当前基地引用；随后摧毁目标也无法推进该任务。

- 入场识别包含地图上的玩家人员（含容器内人员）和本扩展的玩家舰船。
- 删除按累计入场时间和地面人数判定撤退的逻辑。入场、登舰或临时转移期间，只要基地地图仍存在，就继续检查原有胜利条件。
- 保留旧存档 `nmcBaseRetreated` 字段以兼容旧数据，但不再用它停止战场检查或向世界汇报失败。世界接口忽略地图尚在时的旧负向报告。
- 地图确实已移除、基地已销毁或任务已结束时仍保留失败处理；摧毁通讯核心并清除守军、炮塔后仍正常完成和推进下一阶段。
- 地图状态仍通过原有联机主机观察命令传给世界，未增加新的同步入口、随机调用或计时状态。
