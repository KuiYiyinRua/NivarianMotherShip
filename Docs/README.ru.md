# Расширение корабля-матки нивариан

Версия **0.9.6**, RimWorld **1.6**. Языки: упрощённый китайский, английский, русский, японский и французский.

Расширение добавляет 19 видов тактической поддержки, магазин за очки, авианосец, гравитационный корабль и кампанию Континуума из восьми этапов.

## Установка

Скачайте архив мода из [Releases](https://github.com/KuiYiyinRua/NivarianMotherShip/releases) и распакуйте папку NivarianMotherShip в каталог Mods игры. При обновлении замените старую копию.

Включите Harmony, Humanoid Alien Races, Nivarian Race и это расширение в указанном порядке. Выполните также требования базовых модов. Зависимости в архив не включены. Выберите язык в настройках RimWorld и дождитесь перезагрузки данных.

Royalty включает штатные пси-способности; без него используются резервные способности. Адаптер Multiplayer загружается автоматически. Необязательный мод Milira предоставляет батареи корабля. Для кампании нужен военный аддон нивариан; без него исследования поддержки доступны напрямую.

## Игра

Откройте страницу командира в окне поддержки корабля-матки. Протоколы открываются через терминал исследований восходящей связи. Стоимость и ограничения целей указаны в игре.

Для улучшения авианосца нужны десять батарей Milira, для гравитационного корабля две. Запросите улучшение и дождитесь доставки колонистами. После установки топливо расходуется только при взлёте.

В 0.9.6 точное распознавание союзников открывается отдельным исследованием после орбитальной поддержки: 3000 очков исследования, 250 стали, восемь промышленных компонентов и 30 драконьих кристаллов. Защита действует постоянно. Ранее купленная защита сохраняется и автоматически отмечает исследование завершённым.
